# WML-Feedback 1.0.1

Release date: 2026-11-26

## Added
- Backend heading for the customer-approval notice is configurable in Component Options.
- Customer-approval notice text is editable with the Joomla editor, including formatting and links.
- The message shown when a user has no access is editable with the Joomla editor.

## Changed
- The existing texts remain the default values for new installations.
- Clearing either editable text suppresses that corresponding output.

## Preserved
- Frontend access remains controlled by the selected Joomla user and/or selected Joomla user groups (OR logic).
- Super Users retain unrestricted access.
- The Options button remains visible only to Super Users.
